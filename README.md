# Vlens 公式サイト

Windows 11向けアバター・仮想カメラアプリ **Vlens（V Lens）** の紹介サイトです。アプリ本体とは独立したリポジトリで管理します。

## ローカルで表示

Node.js 22以降で実行できます。依存パッケージのインストールやビルドは不要です。

```sh
npm run dev
```

`http://127.0.0.1:4173` を開きます。終了は Ctrl+C。検証は `npm run check`。

## 構成

- `dist/index.html` — 日本語の製品紹介、機能、導入手順、FAQ、配布状況
- `dist/style.css` — PC・スマートフォン対応、動きを減らす設定への対応
- `dist/main.js` — 表情イラストの切り替え
- `dist/favicon.svg` — ブランドアイコン
- `dist/_headers` — 対応ホスト用のセキュリティヘッダー
- `scripts/` — Node.js標準機能だけで動くプレビューと検証

公開するファイルは `dist/` 内だけです。サブディレクトリ配信にも対応します。GitHub Pages・Cloudflare Pagesなどの静的ホスティングで公開できます。ホスティング先は未設定です。`_headers` の対応状況はホストによって異なります。

## 公開内容の方針

アプリ本体は現時点で非公開のため、配布欄は「配布準備中」です。非公開リポジトリやダウンロードできないリリースへのリンクは掲載していません。一般公開するインストーラーと配布条件が決まったら、配布欄・FAQ・冒頭の配布ステータスをまとめて更新してください。

掲載するキャラクターはこのサイト用のオリジナルSVGイラストで、実際のアプリ画面やVRMモデルではありません。第三者のアバターモデル・カメラ映像・ユーザー素材は含みません。

価格、公開日、未確認の性能、未実装機能は掲載していません。全身トラッキングは試験機能として記載しています。サイト自体はカメラ・マイクへのアクセスや解析用トラッキングを行いません。

サイトの公開範囲とアプリの配布条件は別に管理してください。公開リポジトリにした場合も、アプリ本体の公開・無償配布を意味しません。


## ブラウザ検証

WindowsにMicrosoft Edgeがある場合は `npm run check:browser` で、4種類の画面幅、表情切り替え、FAQ、動きを減らす設定を確認できます。専用の一時プロファイルを使用し、普段のブラウザには触れません。スクリーンショットはGit管理外の `.preview/` へ保存します。
